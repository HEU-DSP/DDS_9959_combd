## 1. 硬件信号路径

```
                            STM32H723                           AD9959
                            ────────                           ──────
  LPTIM1 (16 MHz) ──→ DMAMUX Sync Gate ──→ SPI1 DMA (Stream2) ──→ SDIO0 (PD7)
                       (LPTIM1_OUT)   ──→ SPI3 DMA (Stream1) ──→ SDIO1 (PD6)
                                                                    SDIO2 (PD5) = 预留
  TIM2 CH1 (PA0) ──────────────────────────────────────────────→ TIM4 ETR (PE0) [飞线]
       │  PWM 上升沿
       ├── ETRF (COMP1 remap) → TIM2 自复位 → Update → ITR1 ──→ TIM8 Reset
       │                                                         ├─ CH1 (PC6) → IO_UPDATE
       │                                                         └─ CH2 (PC7) → DIO3
       └── SPI1 硬件 NSS (PA15) ──────────────────────────────→ AD9959 CS
                │
                ├── 直连 PB6 (TIM4 CH1) → 捕获 CS↓ 时刻
                └── 直连 PB7 (TIM4 CH2) → 捕获 CS↑ 时刻

  TIM15 CH1 (PC12) ────────────────────────────────────────────→ AD9959 REF_CLK
  USART10 TX (PE3) ──→ 74HC595 #1 DS ──→ QH' ──→ 595 #2 DS
  595 控制: PE2=STCP, PE4=SHCP, PE5=MR, PE6=OE
```

### 关键测试点

| 引脚 | 信号 | 预期波形 | 用途 |
|:--|:--|:--|:--|
| PA0 | TIM2_CH1 | PWM, 频率=sample_rate | DMA 触发基准 + TIM4 ETR 源 |
| PA15 | SPI1_NSS | 每帧一次低脉冲 | AD9959 CS |
| PB3 | SPI1_SCK | 125 MHz 突发 | SPI 时钟 |
| PD7 | SPI1_MOSI | 数据 (4-bit 帧) | AD9959 SDIO0 |
| PD6 | SPI3_MOSI | 数据 (4-bit 帧) | AD9959 SDIO1 |
| PC6 | TIM8_CH1 | 每帧一次正脉冲 | AD9959 IO_UPDATE |
| PC7 | TIM8_CH2 | 每帧一次正脉冲 | AD9959 DIO3 |
| PC12 | TIM15_CH1 | 50 MHz PWM | AD9959 REF_CLK |
| PE0 | TIM4_ETR | 同 PA0 (飞线) | TIM4 计数器复位源 |

## 2. 时序链路

```
   LPTIM1 CNT     0 ──→ ARR ──→ 0 ──→ ...
   LPTIM1_OUT     ────┐         ┌───  (Period match)
                      └─────────┘
   DMAMUX Gate     ===LOCKED===║OPEN║===LOCKED===
                               ║    ║
   TIM2 CH1 (PA0)  ────┐         ┌───  (CCR1 match → ETRF reset TIM2)
                      └─────────┘
   SPI NSS (PA15)   ────────┐   ┌──────
                            └───┘ CS↓ → SCLK+DATA → CS↑
   TIM4 CNT          ──0──1──2──...  (ETR 硬件清零)
                        ↑          ↑
                     CH1 捕获    CH2 捕获
                    (CS↓ 时刻)  (CS↑ 时刻)

   TIM8 CNT          ──0──1──...──CCR1──CCR2──...
                        ↑         ↑       ↑
                   ITR1 复位   IO_UPDATE  DIO3
                   (TIM2 Update)
```

**时序约束**：
- 帧传输时间 = frame_len × 32 ns (4-bit SPI @ 125 Mbps, 每字节 4 SCLK)
- 帧传输时间 < 1 / sample_rate (下一帧触发前必须完成)
- CS↓ 到 CS↑ = 帧长 × 32 ns + NSS 开销 (~16 ns)

└─────────────────────────────────────────────────────────┘

## 4. 初始化序列

```
main()
  │
  ├─ tx_timing.baud_rate = 100000, samples_per_sym = 1
  ├─ TxTiming_Update() → sample_rate=100kHz, lptim_period=159
  │
  ├─ ModCfg_SetCW(0, FTW_10MHZ, 0x3FF)    // mod_cfg[0].cw.ftw
  ├─ sym_buf.ready = true; sym_buf.count = 1
  │
  ├─ HC595_Init()
  │   └─ GPIO 默认: MR=高, OE=高(禁止输出), STCP/SHCP=低
  │
  ├─ AD9959_Init()
  │   ├─ PowerUpSequence()
  │   │   ├─ DDSPWREN1V8D=1, DDSPWREN1V8A=1  (595)
  │   │   ├─ HAL_Delay(10)
  │   │   ├─ DDSPWREN_3V3D=1, DDSCLKMODE33=1  (595)
  │   │   ├─ DDSMASTERRST 脉冲 (低→延迟→高)    (595)
  │   │   └─ HC595_OutputEnable(true)
  │   ├─ ConfigPLL()
  │   │   ├─ BSP_TIM15_SetREFCLK(50MHz) → TIM15 CH1 PWM 启动
  │   │   ├─ FR1: VCO=HIGH, PLL_DIV=20, CP=150uA
  │   │   └─ AD9959_WriteRegister(FR1, 3B) → 阻塞 SPI
  │   ├─ CSR = 0xF0 | 0x00 (4ch enable, 2-wire, MSB first)
  │   └─ AD9959_IOUpdate() → GPIO 脉冲 PC6 → 锁存配置
  │
  ├─ Encoder_BuildBank(&tx_bank[0])       // 生成首帧
  ├─ memcpy tx_bank[1] ← tx_bank[0]      // 克隆到 bank[1]
  ├─ sym_buf.ready = true                 // 重新提交供 ISR 消费
  │
  ├─ Trigger_Init(&trig_cfg)
  │   ├─ BSP_TIM2_SetFreq(100kHz) → ARR=2559, CCR1=1279
  │   ├─ BSP_LPTIM1_SetPeriod(159)  → ARR=159
  │   ├─ BSP_TIM8_SetDelay(CH1, 200), (CH2, 210)
  │   ├─ BSP_TIM4_Start()  → CH1/CH2 IC 使能
  │   └─ BSP_TIM8_Start()  → CH1/CH2 OC 使能
  │
  └─ Trigger_Start()
      ├─ LPTIM1->CNT = 0, TIM2->CNT = 0  (相位对齐)
      ├─ BSP_LPTIM1_Start(0)
      ├─ BSP_TIM2_Start()  → PWM CH1 输出
      └─ BSP_SPI_Both_DMA_Start(bank[0]) → DMA 武装, 等 LPTIM1_OUT
```

## 5. DMA ISR 流程 (100 kHz)

```
HAL_SPI_TxCpltCallback(hspi)
  │
  ├─ BSP_DMA_NotifyComplete(hspi)
  ├─ done_count++ (SPI1 + SPI3 都完成后进入)
  │
  ├─ ds.tim4_last_start/end ← 上一帧值
  ├─ Trigger_GetCaptureTiming(&ds.tim4_cs_start, &ds.tim4_cs_end)
  │   └─ 从 TIM4 CCR1/CCR2 读取 (由 HAL_TIM_IC_CaptureCallback 更新)
  │
  ├─ Trigger_SwapBuffer()
  │   ├─ tx_active ^= 1
  │   └─ BSP_SPI_Both_DMA_Start(新 active bank) → 重新武装 DMA
  │
  ├─ Encoder_BuildBank(TxBuf_GetIdle(), &tx_bank_bytes)
  │   ├─ for i=0..3: if mod_cfg[i].enabled
  │   │   ├─ CW: FrameBuilder_CW(mod_cfg[i].cw.ftw)
  │   │   ├─ FSK: sym_buf bit → mod_cfg[i].fsk.mark/space → Encoder
  │   │   └─ ASK: sym_buf bit → mod_cfg[i].ask.on/off → Encoder
  │   ├─ 消费 1 symbol (sym_buf.count--, count==0→ready=0, free=1)
  │   └─ return false if no frames → Trigger_Stop(), tx_running=false
  │
  └─ 返回

HAL_SPI_ErrorCallback(hspi)
  ├─ ds.dma_error_count++
  ├─ BSP_SPI_Abort(hspi)
  └─ BSP_SPI_Both_DMA_Start(active bank) → 恢复
```

## 6. 主循环 (100ms)

```
while(1) {
    if HAL_GetTick() - last >= 100ms:
        if sym_buf.free:                // Middleware 空闲?
            test_pattern = (++tp) % 3
            case 0: ModCfg_SetCW (0, 10MHz, full)
            case 1: ModCfg_SetFSK(0, 10M/11M, full)
            case 2: ModCfg_Disable(0); ModCfg_SetCW(1, 10MHz, half)
            sym_buf.ready = true        // 提交
            sym_buf.free  = false
        
        if !tx_running && sym_buf.ready:
            Trigger_Restart()
            tx_running = true
}
```

**调试**: 在调试器中观察：
- `ds.frame_count` — 总帧数
- `ds.tim4_cs_start / tim4_cs_end` — 最新帧 CS 边沿的 TIM4 ticks
- `ds.dma_error_count` — DMA 错误计数
- `mod_cfg[0..3]` — 每通道调制参数 (cw/ftw, fsk/mark/space, ask/on/off)
- `sym_buf.ready / sym_buf.free / sym_buf.count` — 符号缓冲状态
- `tx_active` — DMA 正在读取的 bank (0 或 1)
- `tx_running` — 发射是否运行中

## 7. 调试接口速查

```c
// === 全局调制参数 (调试器直接写) ===

mod_cfg[0].cw.ftw        = FTW_10MHZ;   // CH0 CW 频率
mod_cfg[0].fsk.asf       = 0x3FF;       // CH0 幅度 (CW 也用它)
mod_cfg[0].enabled       = true;
mod_cfg[0].mode          = CH_MODE_CW;

mod_cfg[1].fsk.ftw_mark  = FTW_10MHZ;   // CH1 FSK mark 频率
mod_cfg[1].fsk.ftw_space = FTW_11MHZ;   // CH1 FSK space 频率
mod_cfg[1].fsk.asf       = 0x200;       // CH1 半幅
mod_cfg[1].mode          = CH_MODE_FSK;
mod_cfg[1].enabled       = true;

mod_cfg[2].enabled       = false;       // CH2 关闭
mod_cfg[3].enabled       = false;       // CH3 关闭

// === 快捷宏 (代码/调试器 Evaluate) ===

ModCfg_SetCW (0, FTW_10MHZ, 0x3FF);
ModCfg_SetFSK(0, FTW_10MHZ, FTW_11MHZ, 0x3FF);
ModCfg_SetASK(0, FTW_10MHZ, 0x3FF, 0x020);
ModCfg_Disable(2);

// === 符号缓冲区 ===

sym_buf.data[0] = 0xAA;   // 原始 bit 流 (FSK/ASK 用)
sym_buf.count  = 8;       // 8 bits
sym_buf.ready  = true;    // 提交 → ISR 下一帧消费
sym_buf.free   = false;

// === 手动提交 (从调试器) ===

if (sym_buf.free) {
    ModCfg_SetCW(0, FTW_10MHZ, 0x3FF);
    sym_buf.ready = true;
    sym_buf.free  = false;
}

// === 寄存器级调试 ===

// 初始化阶段软件 IO_UPDATE (AD9959_Init 内部调用)
AD9959_IOUpdate();     // GPIO 脉冲 PC6, 锁存 PLL/CSR

// 阻塞 SPI 写寄存器 (init only)
uint8_t fr1[3] = {0xAB, 0x00, 0x00};
AD9959_WriteRegister(AD9959_REG_FR1, fr1, 3);

// === 触发控制 ===

Trigger_Stop();        // 停止 LPTIM1 + TIM2 + TIM8 + DMA
Trigger_Restart();     // 相位重新对齐, 恢复发射
Trigger_Start();       // 首次启动 (Trigger_Init 之后调用)

// === 时序测量 (TIM4 捕获值, 单位: TIM4 ticks @ 128 MHz) ===

Trigger_GetCaptureTiming(&t_cs_start, &t_cs_end);
// t_cs_start = DMA 触发 → CS↓ 延时
// t_cs_end   = DMA 触发 → CS↑ 延时
// CS 活跃时间 = t_cs_end - t_cs_start (ticks)
// 换算: 1 tick = 1/128 MHz ≈ 7.8 ns
```

## 8. 当前已知限制

| 项目 | 说明 |
|:--|:--|
| SDIO2 (PD5) | 预留，未使用 |
| 多通道帧 | `Encoder_BuildBank` 支持遍历 4 通道拼接，帧长受 `FRAME_BUF_SIZE=64` 约束 |
| FSK/ASK 参数 | 已通过 `mod_cfg[ch].fsk/ask` 暴露给 App |
| 读寄存器 | `AD9959_ReadRegister()` 为空实现，未验证 |
| PSRAM | `aps6404.h` 仅骨架，未实现 |
| TIM8 延迟校准 | `P1_CH1_DELAY=200, P1_CH2_DELAY=210` 为估计值，需用 TIM4 捕获值校准 |
| 多板同步 | FR2 sync 位域已定义但未使用 |
| sym_buf 每帧仅 1 symbol | 当前 `Encoder_BuildBank` 每帧消费 1 symbol。多 symbol/帧需扩展 |
